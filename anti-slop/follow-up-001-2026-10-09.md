# PitchTicker audit follow-up

Implemented the five findings from audit-001 after user approval.

1. Home now has one match board. Fresh live fixtures replace cached fixtures with the same ID, additional live fixtures are retained, and the previous eight-live-fixture limit is removed. Live and text filters work together. Repeated league footers are omitted on home; league navigation remains available in the directory.
2. Scores lead the mobile layout. League navigation becomes a native disclosure below the board and opens by default at desktop widths. At 390px the first fixture starts at y=397px, previously y=492px, with the same fixture-only preview notice present in both measurements.
3. CMS has a compact header, scraper rows with separators and an independently sized news action. Running jobs remain above the triggers. Forms, routes and season-loading skeleton remain intact.
4. Home dates, match groups, league directory and news use separators instead of repeating rounded cards. The match heading has stronger emphasis; standings remain a grouped panel. No decorative assets or new motion were introduced.
5. Fixture detail now has a descriptive screen-reader h1 while preserving the visible scoreboard hierarchy.
